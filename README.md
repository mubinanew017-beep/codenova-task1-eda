# Palmer Penguins — Exploratory Data Analysis (EDA)

## 1. Project Overview
This project performs Exploratory Data Analysis (EDA) on the Palmer Penguins dataset. The goal is to explore penguin species, examine physical measurements, identify missing values, and visualize patterns in the data.

## 2. Dataset
- **Dataset:** Palmer Penguins
- **Records:** 344
- **Columns:** 8
- **Data format:** CSV

## 3. Technologies Used
- Python
- Pandas — data loading and manipulation
- NumPy — numerical operations
- Matplotlib — data visualization
- Seaborn — statistical plots

## 4. Work Performed
- Loaded and inspected the dataset.
- Checked dataset dimensions and column information.
- Identified missing values.
- Calculated descriptive statistics.
- Analyzed the distribution of penguin species.
- Created a species count plot.
- Created a body mass boxplot.
- Generated a correlation heatmap.
- Handled missing values and saved a cleaned dataset.

## 5. Output Files
- `eda_analysis.py` — Python analysis script
- `penguins.csv` — original dataset
- `penguins_cleaned.csv` — cleaned dataset
- `species_count.png` — species count visualization
- `body_mass_by_species.png` — body mass comparison
- `correlation_heatmap.png` — correlation heatmap

## 6. Conclusion
This project demonstrates how Python can be used to inspect, clean, summarize, and visualize a real-world dataset. The analysis helps identify differences between penguin species and understand relationships among numerical measurements.

## 7. How to Run
From the main project folder, activate the virtual environment and run:

```bash
python Task1-EDA/eda_analysis.py
```
